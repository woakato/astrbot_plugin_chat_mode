# 提示词规则库（prompt_kb）

本目录存放 RP 配图用的 NAI 提示词知识源，由 `chat_mode_prompt_kb.py` 做**本地关键词检索**，只把命中的段落注入提示词——不调用模型，也不增加工具调用。

- `rules.md`：NovelAI 提示词规则整理（主提示词结构、权重语法、画师串、多角色、质量标签与负面预设、文字渲染、参数、API 注意事项等）。
- `recipes.md`：实测过的具体配方（分镜、双人、POV、多人构图、姿势加权、道具与体液写法等），每条都带实测条件。

两个文件来自 `nai-prompting` skill（2026-10 版本），原样保留，未改动正文。

## 检索是怎么工作的

1. 按 `##` / `###` 标题把文件切段；
2. 每段建两组词：英文 tag（长度 ≥3 的拉丁词）与中文二元组（去掉「我们 / 这个 / 可以」等停用词）；
3. 本轮查询由「场景设定 + 上一张配图的 Tag + 本轮用户正文 + 角色回复 + 附加要求」拼成；
4. 打分：标题命中权重 4，英文 tag 命中 2，中文二元组命中 1；取分数最高且不超过 `rp_image_rule_max_sections` 的段，按 `rp_image_rule_budget`（默认 1200 字符）截断输出。

## 怎么更新

直接用新的 `rules.md` / `recipes.md` 覆盖本目录文件即可——文件修改时间变化会让缓存失效，无需重启（下次配图生效）。也可以把 `rp_image_rule_path` 指向自建目录，放任意数量的 `##` 分节 Markdown。

注意：预算很小（默认 1200 字符），写段时把最关键的写法放在段首，长表格与来源列表放在段尾；段标题里带上会被剧情提到的关键词（如「分镜」「双人」「POV」）能显著提高命中率。
